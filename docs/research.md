# 조사

주제를 정하기 전에 회사의 공개 방향, 국내 개인·학생 프로젝트, 대회, 국내 현업 사례를 조사했다. 아래는 그 요약이고, 이 프로젝트가 무엇을 비워 두고 무엇을 채우려 했는지를 정리한다.

## 방법과 한계

- 검색(WebSearch)과 페이지 읽기(WebFetch)로 조사했다. 한국 사이트 다수와 대회 사이트가 읽기 차단이라, 본문을 읽은 것과 검색 요약만 본 것을 구분했다
- 근거 등급: A는 원문 직접 읽음, B는 GitHub README를 읽음(요약 도구 경유라 숫자는 원문 확인 필요), C는 메타데이터만, D는 검색 요약만이다
- 검색 한도 때문에 일부 질의는 하지 못했다. 합격 후기, 면접 후기, 채용 절차는 찾지 못했다
- 검색에 나온 동명의 다른 회사 정보는 쓰지 않았다

## 회사가 공개한 방향 (D)

- 시설관리 소프트웨어 유비스 마스터를 만드는 소규모 회사이고, 정부청사 시설관리시스템(G-FMS) 구축에 참여했다. 고장수리, 설비, 안전, 행정 기능이 있다
- 2026년 보도에 따르면 유비스 마스터 Pro의 2026년형이 축적된 데이터로 장비 장애를 예측하고 운영 시나리오를 제시하는 AI 기능을 강화한다
- 쌓이는 데이터는 점검 이력, 고장·A/S, 자재, 에너지·계측, 순찰(NFC, QR, 비콘), 산업안전이다
- 공고 문구는 서비스 운영, 실증 프로젝트, 고객 맞춤형 모델이다. 규모가 작아 데이터 정리부터 모델, API까지 한 사람이 맡을 가능성이 크다(추정)

## 국내 개인·학생 프로젝트 (B 27건, D 11건)

- 제조 예지보전(센서 분류, 이상 탐지)이 가장 많았다. 직접 읽은 29건 중 16건이다. 건물·시설관리 맥락은 1~2건이었다
- 건물 전력 예측 대회 코드가 그다음이다. 같은 LightGBM 계열이 반복된다
- 공통 약점은 합성 데이터만 쓴 것, 정상과 이상이 다른 날에 수집된 것, 랜덤 분할 누수, 성능 숫자가 없는 README였다
- 민원은 텍스트 분류나 이미지 탐지로만 다뤘고 설비 예측과 연결한 것은 못 찾았다
- 작업지시 이력(CMMS)을 분석한 프로젝트는 한 건도 못 찾았다
- 고장 정의를 평가 대상으로 삼은 프로젝트는 못 찾았다. 정상과 이상의 정의, 예측 대상이 정해지지 않았다고 스스로 적은 저장소는 있었다

## 대회 (A 2건, B 다수, D)

- 에너지 공단과 데이콘의 전력사용량 예측 대회가 대표적이다. 상위권은 건물별·유형별 모델, 기상 파생 변수, GBDT 앙상블을 쓴다
- 빠진 것으로 보이는 것은 서비스화, 운영과 모니터링, 현장 검증, 새 건물 콜드스타트, 작업지시와 고장 이력 데이터다(대회 규칙을 읽어 확인한 것은 아니고 읽은 자료에서 발견되지 않았다는 뜻이다)

## 국내 현업 사례 (D)

- 현업은 고장을 계통과 유형으로 나누어 정의한다. 한 가전 업체는 고장을 네 계통으로 나눠 분석하고, 승강기 업체는 정지 고장을 지표로 쓴다
- 성과를 정지 건수, 출동 건수, 비용으로 말한다
- 데이터 수집, 표준화, 연결이 병목이라는 서술이 반복된다. 정비 이력과 작업일지를 핵심 자료로 보는 곳도 있다
- 드리프트 감시, 재학습 주기 같은 운영 문제는 읽은 요약에 거의 안 나왔다

## 이 프로젝트에 준 시사점

| 조사에서 본 것 | 이 프로젝트에서 한 것 |
|---|---|
| 고장 정의서가 없는 학생 프로젝트가 많아 보임 | 정의를 YAML 파일로 쓰고 정의마다 라벨 품질을 잼 |
| 작업지시와 민원을 결합한 프로젝트가 없었음 | 민원이 작업지시를 받쳐 주는 정의(d3, d4)와 민원 군집 |
| 합성 데이터만 쓰는 것이 공통 약점 | 합성 데이터의 장점인 정답을 써서 정의를 채점하고, 합성의 가정을 따로 적음 |
| 랜덤 분할 누수 | 시간 분할, 미래 기록을 잘라도 특징이 같은지 테스트 |
| 현업은 현장·고객별 적용을 말함 | 현장 확인으로 고객별 정의를 검증하는 절차와 확인표 CLI |
| 운영과 모니터링이 빠져 있음 | 기록 습관 변화 감시 |
| 한계가 "실데이터 필요"로 끝남 | 실제 로그에 적용하는 순서와 합성에서 못 보인 것을 적음([실제 로그에 적용하기](real-data.md)) |

## 읽지 못한 것

- 채용 공고의 본문과 채용 절차
- 대회 상위 솔루션 일부와 수상자 인터뷰
- 학술 논문 본문(검색 요약만)
- 정부·기관 보도자료 본문
